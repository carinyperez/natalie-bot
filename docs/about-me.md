# About me

I'm Cariny Perez, the engineer building Natalie Bot.

## What I do

I'm a software engineer who builds web apps and APIs in TypeScript. Natalie Bot uses tools I already know: React Native with Expo on the phone, and a Serverless TypeScript backend on AWS.

## Why I'm building Natalie Bot

Making a good reel from a phone video takes cropping, finding music and syncing it, usually across several apps. I want new creators without editing skills to get there with one upload and one tap.
